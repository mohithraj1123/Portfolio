Featured Project

GeneRisk AI

DNA-Based Cancer Risk Prediction Platform

GeneRisk AI predicts cancer risk from DNA-based features. I built a comparison framework across five algorithms: XGBoost, Random Forest, LightGBM, SVM and neural networks. That let me pick the best performer based on evidence instead of habit.

SHAP explainability shows which features drive each prediction, so the output is interpretable rather than a black box. The model is served by a Flask API on Railway, and the user dashboard, with a Three.js 3D frontend, runs on Next.js and Vercel.

97.37% Accuracy
